## CodeQL finding

Check run 123967560121 reports `js/weak-cryptographic-algorithm` at `src/qobuz.js:9`.
This is the existing MD5 operation used by Qobuz's `track/getFileUrl` request-signature protocol.
The rotation changes add credential sources flowing into that existing signer; they do not introduce
a new hashing algorithm. `test/qobuz.test.js` pins the client's known signature vectors.

Replacing MD5 with SHA-256 would break those signatures and upstream requests. This is a protocol
constraint, not a password-storage choice. On 2026-10-31 the owner authorized handling this
exception. Alert #7 was dismissed as "won't fix" with the protocol constraint and compatibility
vectors recorded in its dismissal comment. This accepts only that upstream interoperability risk;
no global CodeQL exclusion or source suppression was added. CodeQL remains enabled.
