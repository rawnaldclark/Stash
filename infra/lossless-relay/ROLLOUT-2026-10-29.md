# Relay install and minimum-build gates

Before deployment, the live rollback versions were:

| Worker | Rollback version | Free daily | Minimum build | Require install |
| --- | --- | --- | --- | --- |

The intended deployment keeps free daily at 300 and sets minimum build to 0 on both
workers. Tidal requires installs for app requests, with the web lanes exempt.
The fallback for missing/invalid FREE_LOSSLESS_DAILY changes from 500 to 300,
with a once-per-isolate error log.

Every plain-text variable, D1 binding, rate-limit binding, compatibility date and flag
was compared with live. Configs preserve the live Qobuz overrides/uncapped labels and
Tidal caps (global 63787, daily per seat 17664, hourly 828, gap 2 seconds).
Compiled bundles were compared against the downloaded live scripts. The branch also
preserves live-only Qobuz account overrides, QOBUZ_ACCOUNTS_RECOVERED_5 support,
and Tidal explicit-content search metadata; deploying the original master code
would have removed these. No account secrets, tokens, or database rows are changed.

The web plugin forwards X-Access-Token and Accept, without install/signature headers.
It uses ?web=1, ?web=mse, or ?aac=only; the app's AAC-only URL adds hires=0.
The Qobuz mint endpoint is not used by the web player.

Tidal signing was introduced in aded9870 and first released in v0.9.117
(versionCode 153). The running app versionCode supplies X-Stash-App-Build on
Qobuz mint and Tidal stream requests, including custom endpoints.

The legacy unsigned share over the previous 24 hours could not be estimated:
fully absent install headers return a legacy caller without a distinguishing log.
Malformed/invalid signatures are logged, but cannot measure all unsigned traffic.
